# 낙서 서바이벌

내가 그린 모양대로 무기가 되는 3D 낙서 게임이다. 모드는 두 가지다.

- **난투**: 링크를 열면 자동으로 빈자리가 있는 방에 들어간다. 한 방에 최대 6명이다. 친구 방은 QR 코드로 초대할 수 있다.
- **혼자 모험**: 이야기 4장과 보스 4마리가 있는 로그라이크 모드다. 학교 방화벽 때문에 난투 연결이 안 될 때도 혼자 모험은 할 수 있다.

주소: https://lo4lolo.github.io/nakseo-survival/

## 실행

빌드할 필요가 없다. 폴더를 웹 서버로 열면 된다.

```bash
python -m http.server 8830
```

브라우저에서 `http://localhost:8830`을 연다. 인터넷이 필요하다. Three.js, PeerJS, qrcode-generator를 CDN에서 불러오고, 사람을 찾을 때 PeerJS 공개 서버를 쓰기 때문이다.

**배포**: 폴더를 통째로 Netlify(드래그 앤 드롭)나 GitHub Pages에 올리면 된다. 서버 코드가 없다.

## 친구 초대 (QR)

"친구랑 방 만들기"를 누르면 `#r-xxxxxx` 주소의 친구 방이 만들어지고 초대 창이 뜬다. 초대 창에는 QR 코드와 링크가 있다. 휴대폰 카메라로 QR을 찍으면 같은 방으로 바로 들어온다. 게임 중에도 오른쪽 위 "초대 (QR)" 버튼으로 다시 열 수 있다.

## 혼자 모험 (js/solo.js)

한 판은 4장이고, 장마다 **방 1(웨이브 2) → 방 2(웨이브 3) → 보스** 순서로 진행한다. 쓰러지면 처음부터 다시 한다. 적의 공격은 먼저 바닥에 빨간 원이나 선으로 예고된다.

| 장 | 이야기 | 보스 | 보스 공격 |
|---|---|---|---|
| 1장 연습장 | 지우개 군단이 쳐들어왔다 | 말랑 지우개 | 뛰어올라 찍기, 돌진, 부하 부르기 |
| 2장 수학 공책 | 자 병사가 줄 맞춰 돌진한다 | 컴퍼스 기사 | 빙글빙글 회전, 연필심 부채꼴 발사, 돌진 |
| 3장 미술 스케치북 | 물감이 번졌다 | 물감 괴물 | 물감 웅덩이(느려짐), 사방 발사, 방울 부르기 |
| 4장 지우개 왕국 | 공책 전체를 지우려 한다 | 지우개 대왕 | 3단계. 마지막 단계에서 공책 가장자리를 지운다 |

보스는 체력이 줄면 화가 나서 공격이 빨라지고 새 기술을 쓴다.

**적 7종**: 지우개 벌레, 지우개 가루(빠름), 자 병사(예고 뒤 돌진), 번짐 방울(쓰러지면 둘로 나뉨), 물감 붓(멀리서 발사), 수정액 병(느리고 단단함), 작은 방울.

**로그라이크 스티커**: 방을 깰 때마다 3장 중 1장을 고른다. 같은 스티커를 여러 번 모을 수 있다(최대 개수 있음). 체력이 60% 아래면 "쉬는 시간(모두 회복)"이 섞여 나온다. 스티커 고르는 화면에서 무기를 다시 그릴 수 있다.

| 스티커 | 효과 |
|---|---|
| 🖊️ 굵은 펜 | 공격력 +20% |
| 📏 긴 자 | 무기 크기 +15% |
| 🪶 가벼운 손 | 공격 속도 +15% |
| 📔 튼튼한 표지 | 최대 체력 +25 |
| 🫙 잉크병 | 잉크 최대 +40, 회복 +30% |
| ⭐ 반짝 별 | 12% 확률로 피해 2배 |
| 🧃 잉크 흡수 | 적을 쓰러뜨리면 체력 +4 |
| 👟 날쌘 운동화 | 이동 +12%, 구르기 대기 -20% |
| ⚡ 번개 구르기 | 구르다 닿은 적에게 피해 |
| 🌵 가시 갑옷 | 맞으면 둘레 적에게 반격 |
| 🧴 딱풀 | 땅 그림이 오래가고 1개 더 |
| 🩹 반창고 | 회복 원 효과 2배 |
| 💥 묵직한 손 | 밀쳐내기 +40% |
| 🧲 자석 | 잉크 방울을 멀리서 끌어옴 |
| 🍀 지우개 부적 (드묾) | 쓰러지면 한 번 되살아남 |

- 적을 쓰러뜨리면 잉크 방울(잉크 +25)이나 가끔 하트(체력 +12)가 떨어진다.
- 적도 내 벽에 막히고, 가시밭에 찔린다. 물감 방울은 벽에 막히고 무기로 쳐서 튕겨 낼 수 있다.
- `Esc`로 멈춘다. 탭을 옮기면 저절로 멈춘다.
- 기록(최고 도달, 클리어 횟수, 가장 빠른 시간)은 브라우저에 저장된다(`nakseo-survival-solo-v1`).

## 난투 규칙

| 단계 | 내용 |
|---|---|
| 연습 | 혼자일 때. 허수아비를 상대로 무기와 땅 그리기를 연습한다 |
| 무기 그리기 (25초) | 2명 이상 모이면 모두 스케치북이 열린다 |
| 난투 | 원 둘레에 흩어져 시작한다. 20초 뒤부터 지우개가 가장자리부터 공책을 지운다(자기장). 마지막 한 명이 우승한다 |
| 결과 (6초) | 우승자를 발표하고 다음 판으로 넘어간다 |

- 난투 중에 들어온 사람은 그 판을 관전하고, 다음 판부터 참가한다.
- 목록의 왕관은 우승을 가장 많이 한 사람에게 붙는다. 우승 횟수는 브라우저에 저장된다.

## 그림 판정 (js/recognize.js)

AI 없이 선의 모양에서 숫자를 뽑아 판정한다. 같은 그림이면 어느 컴퓨터에서 계산해도 같은 결과가 나온다.

**무기** (위에서부터 먼저 맞는 규칙이 적용된다)

| 무기 | 그리는 법 | 판정 기준 |
|---|---|---|
| 방패 | 손잡이 가까이 큰 동그라미 | 닫힌 도형, 넓이 6000 이상, 중심이 손잡이에서 170px 안 |
| 망치 | 끝에 큰 덩어리 | 닫힌 도형, 넓이 2800 이상, 멀리 있음 |
| 채찍 | 구불구불 길게 | 굽는 방향이 3번 이상 바뀌고, 뾰족한 꺾임이 3개 이하 |
| 창 | 아주 길고 가늘게 | 사거리 320px 이상, 폭 40px 이하 |
| 검 | 그 밖의 모양 | 기본 무기. 세 번째 콤보는 회전 베기 |

- **가시**: 뾰족한 꺾임이 4개 이상이면 피해가 최대 40% 늘어난다.
- **잉크 색**: 먹물은 피해 +15%, 불꽃은 화상, 물은 느려짐, 덩굴은 묶임.
- **무게**: 잉크를 많이 쓰고 닫힌 도형이 클수록 세고 넓게 밀어내지만, 공격이 느려지고 걸음도 느려진다.

**땅에 그리기** (잉크 게이지를 쓰고, 한 사람에 최대 3개)

| 모양 | 되는 것 | 효과 |
|---|---|---|
| 곧은 선 | 벽(9초) | 모두 못 지나가고, 벽 너머에서 온 공격을 막는다 |
| 지그재그 | 가시밭(7초) | 그린 사람이 아닌 다른 사람이 밟으면 아프고 느려진다 |
| 동그라미 | 회복 원(6초) | 안에 있는 사람은 누구든 체력이 찬다 |

## 멀티 구조 (js/net.js)

- **자동 방**: 주소 끝에 `#방이름`이 없으면 공개 방(plaza)에 들어간다. 6명이 차면 plaza-n2, n3 순서로 다음 방으로 넘어간다. "친구랑 방 만들기"를 누르면 `#r-xxxxxx` 주소의 친구 방이 만들어진다.
- **방장**: 방 이름으로 정해진 PeerJS 주소를 먼저 차지한 사람이 방장이 된다. 방장은 참가자 명단을 돌리고 판을 진행한다(그리기 → 난투 → 결과). 방장이 나가면 남은 사람이 이어받는다.
- **연결**: 참가자끼리 모두 직접 연결한다(그물 구조). 각자 자기 상태(위치, 체력, 공격 동작, 무기 그림, 땅 그림)를 1초에 약 20번 보낸다. 무기 그림은 짧은 글자로 줄여서 보내고, 받는 쪽이 직접 성능을 계산한다.
- **판정**: 맞았는지는 맞는 사람 화면이 정한다. 킬은 쓰러진 사람이 "누구에게 당했는지"를 알리면 공격한 사람이 센다.
- **한계**: TURN 서버가 없어서, 학교 방화벽이 WebRTC를 막으면 연결되지 않을 수 있다. 그럴 때는 혼자 연습만 된다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `js/util.js` | 수학, 색, 선 다루기, 선 ↔ 짧은 글자 |
| `js/audio.js` | 효과음(Web Audio로 만듦) |
| `js/recognize.js` | 그림 판정(순수 함수), 예시 그림 |
| `js/scene.js` | 3D 무대, 공책 바닥, 지우개 자기장, 효과, 카메라 |
| `js/rig.js` | 캐릭터 몸, 그림 → 3D 무기, 공격 자세 |
| `js/net.js` | 자동 방 연결(PeerJS) |
| `js/sketch.js` | 스케치북 화면 |
| `js/game.js` | 전투, 땅 그리기, 판 진행, 화면, 입력, QR 초대 |
| `js/solo.js` | 혼자 모험: 스토리, 적, 보스, 스티커, 결과 |

JS나 CSS를 고치면 `index.html`의 `?v=숫자`를 올린다. 그래야 브라우저가 옛 파일을 캐시에서 쓰지 않는다.
